# Know iOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现首页跨领域精选、领域卡片流与统一排版双语阅读的原生 iOS 客户端。

**Architecture:** SwiftUI 导航和分页卡片共用 FeedStore，URLSession 读取后端契约，SwiftData 保存收藏、已读和浏览位置。结构化正文由原生组件渲染，不加载来源网页脚本。

**Tech Stack:** iOS 17+、SwiftUI、SwiftData、URLSession、XCTest、Xcode 16+；XcodeGen 生成项目。首版不引入第三方 UI SDK。

**Spec:** `docs/superpowers/specs/2026-10-14-know-design.md`。依赖 `docs/superpowers/plans/2026-10-14-know-backend.md` 任务 1 的 `shared/api-v1.md` 及样本，联调依赖后端任务 6。

## Global Constraints

- 使用现有 checkout，不创建额外 Git worktree。
- iOS 17+、SwiftUI、SwiftData；无账号、社交、个性化推荐或系统通知。
- 首页最多 10 篇、七个领域入口、每领域最多 10 篇；不足时显示实际数量。
- 左右滑动切换导读卡片；点击进入全文，不把滑动解释为评价。
- 当日精选可回看，后续库存排除已读及已有队列内容。
- 到期只退出推荐池，不删除本地收藏和历史。
- 中英文来源混合；统一排版原文与中文译文，明确标注机器翻译和出处。
- 支持动态字号、深浅色、VoiceOver 和上一篇／下一篇操作。
- 当前机器是 Linux，无 Swift/Xcode；iOS 构建、模拟器和设备验证须在 macOS 执行，源码审查不能替代。

## Review Focus

1. 切换领域时旧网络响应迟到：不覆盖新领域内容（任务 1）。
2. API 分页重复或一页全部已读：跳过重复、继续前进、最终正常结束（任务 2）。
3. 超长标题、最大辅助字号和 VoiceOver：可阅读可操作，不强制固定文字高度（任务 2、4）。
4. 译文缺失、正文移除或离线：提供真实状态，原文可用时仍可读（任务 3）。
5. 收藏后过期、重启或正文更新：收藏不丢失，已读身份与缓存版本独立（任务 1、3）。

## 文件边界与运行环境

`ios/project.yml` 描述主 app、单元测试和 UI 测试目标；`ios/Know/App/` 负责入口和依赖注入；`Models/` 保存契约；`Networking/` 负责 HTTP；`Persistence/` 保存本地数据；`Features/Feed/`、`Features/Reader/`、`Features/Library/` 按用户流程组织。

XcodeGen 输出 `ios/Know.xcodeproj`，生成项目作为构建产物忽略；提交项目描述和共享构建设置。模拟器使用本机可用的 iOS 17+ iPhone，运行脚本从 `simctl list devices available` 解析并选择 UDID，不硬编码不存在的机型。默认 app 展示后端未配置状态，不默认填充演示文章；样本仅通过 UI 测试启动参数注入。

## 测试断言锚点

以下 XCTest 断言在相应任务的测试函数中执行；数据由任务夹具或独立联调环境提供，不能当作已验证结果。

```swift
// Task 1 — testSharedFixturesDecode / testBookmarkSurvivesExpiryAndRestart
XCTAssertEqual(DomainID.allCases.count, 7)
XCTAssertFalse(detail.original.isEmpty)
XCTAssertTrue(reopenedLibrary.isBookmarked(articleID))
// Task 2 — testLateResponseCannotReplaceNewDomain / testDuplicateAndReadOnlyPagesAdvance
XCTAssertTrue(store.cards.allSatisfy { $0.domainID == .historyCivilization })
XCTAssertEqual(Set(store.cards.map(\.id)).count, store.cards.count)
// Task 3 — testFailedTranslationLeavesOriginalReadable
XCTAssertFalse(store.detail!.original.isEmpty)
XCTAssertEqual(store.detail!.translationStatus, .failed)
// Task 4 — testLiveEnglishTranslationToggle
XCTAssertTrue(app.staticTexts["机器翻译"].exists)
XCTAssertTrue(app.buttons["原文"].exists)
```

Swift DomainID case 使用驼峰名称，rawValue 固定为后端 snake_case ID，例如 `historyCivilization = "history_civilization"`；不能依赖默认枚举名称编码。
